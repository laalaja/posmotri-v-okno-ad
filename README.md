# Посмотри в окно

Учебная работа по макету Яндекс Практикума: поиск видеороликов по городу и времени суток.

## Запуск

Откройте `index.html` в современном браузере. Для разработки удобнее запустить локальный сервер из папки проекта:

```sh
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Для получения карточек, изображений и видео нужен интернет и доступ к API `https://v-content.ffapi.ru`.

## Реализация

- Макет рассчитан на страницу шириной 1200 px. Основной блок шириной 1140 px расположен по центру окна по обеим осям.
- Видеоплеер, поисковая форма, прокручиваемый список и кнопка подгрузки оформлены по макету.
- Реализованы состояния наведения, нажатия, клавиатурного фокуса, выбранных чекбоксов и текущей карточки.
- Длинные названия сокращаются многоточием, описание ограничено четырьмя строками.
- Прелоадеры и сообщения об ошибках остаются внутри соответствующих блоков.
- HTML, локальные шрифты и CSS служебных компонентов взяты из официального стартового репозитория без изменений. В JavaScript по предоставленной рекомендации заменён только `BASE_URL` на `https://v-content.ffapi.ru`. Вёрстка выполнена в `styles/style.css`.

## Проверка

В Chrome проверены загрузка пяти карточек и видео через рабочий API. На изолированных тестовых данных проверены переключение видео, подгрузка следующих пяти карточек, фильтры поиска, пустой результат, границы прелоадеров, состояния чекбоксов, наведения и нажатия, а также клавиатурный фокус. Проверена геометрия на окнах 1200×800 и 1920×1080. Тестовые данные в проект не входят. Автотесты Практикума и проверка в Firefox не запускались.
